# Еталонні описи для побудови сценарію з опису (F3-105)

Кожен `*.json` — один випадок: `id`, `description` (як писав би користувач) і `expect` — що має бути в побудованому сценарії.

| Ключ `expect` | Значення |
|---|---|
| `trigger` | допустимі типи тригера (вузол без вхідних з'єднань) |
| `requireTypes` | список груп; з кожної групи в сценарії має бути хоча б один тип |
| `minNodes` / `maxNodes` | межі кількості вузлів |
| `minBranches` | скільки вузлів мають хоча б два різні виходи, що використовуються |
| `minLanes` | скільки доріжок у `business.lanes` |

Прогін: `openbp draft-eval --workflow <id порожнього сценарію> [--cases tests/drafter-cases] [--model qwen3:14b] [--out report.md]`
проти запущеного AI_BPMS (модель — з «Налаштування → Помічник»); див. `docs/workflow-drafter.md`.
